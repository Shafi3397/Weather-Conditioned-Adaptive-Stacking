# GitHub publication checklist

- [ ] Confirm all course-assignment redistribution rules and coauthor permissions.
- [ ] Confirm the IEEE-style coursework manuscript's current status (not published unless accepted).
- [ ] Download `Combined.csv` from the authorized dataset source; verify columns.
- [ ] Install dependencies in an isolated environment.
- [ ] Run `python src/wcas.py` and examine errors/warnings.
- [ ] Compare resulting numerical metrics, figures and methods with the submitted manuscript.
- [ ] Update README with confirmed author(s), affiliation and source URL.
- [ ] Decide whether to publish the manuscript PDF (copyright/permissions).
- [ ] Decide license: MIT if all necessary rights are yours and that is your intention.
- [ ] Run `git status` and confirm no dataset, API tokens or large generated files will be committed.
- [ ] Create a public GitHub repository and push files.
- [ ] Add repository topics, short description and optionally screenshot figures.
